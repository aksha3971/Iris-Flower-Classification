# Iris Flower Classification using Machine Learning

## Project Overview
This project uses machine learning to classify Iris flowers into three species based on their physical measurements. A Random Forest Classifier is used to train the model and predict the species.

## Dataset
- Total Samples: 150
- Species: Iris-setosa, Iris-versicolor, Iris-virginica
- Features:
  - Sepal Length
  - Sepal Width
  - Petal Length
  - Petal Width

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Machine Learning Algorithm
Random Forest Classifier

## Model Performance
- Training Samples: 120
- Testing Samples: 30
- Accuracy: 90%

## Project Steps
1. Data loading
2. Data cleaning
3. Exploratory Data Analysis (EDA)
4. Data visualization
5. Train-test splitting
6. Model training
7. Prediction
8. Model evaluation
9. Feature importance analysis

## Results
The model achieved 90% accuracy on the test dataset. Petal length and petal width were identified as the most important features for classification.

## Conclusion
This project demonstrates how machine learning can be used to classify flower species based on measurements and how model performance can be evaluated using accuracy and a classification report.
